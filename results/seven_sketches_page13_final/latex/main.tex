\begin{definitionbox}[]
정의 1.30. 집합 X 위의 전순서 관계는 X의 이진 관계이며, 내항 기호 ≤로 나타내며 다음 조건을 만족한다: (a) x ≤ x; 그리고 (b) 만약 x ≤ y이고 y ≤ z이면 x ≤ z. 첫 번째 조건은 반사성이라고 하고 두 번째 조건은 전이성이라고 한다. x ≤ y이고 y ≤ x인 경우, x ≡ y 라고 쓰고 x와 y가 동치라고 한다. 집합과 전순서 관계로 구성된 쌍 (X, ≤)를 전순서라고 한다.
\end{definitionbox}


1.31.  반사성과 전이성은 정의 1.18에서 알 수 있듯이 친숙한 개념입니다. 전순서는 대칭 조건이 없는 동치 관계와 같습니다.

\begin{examplebox}[Example  1.33]
(여이산 전순서) 모든 집합에서 우리는 그 여이산 전순서 $(X, \leq)$ 를 구성할 수 있습니다.  $X × X ⊆ X × X$ 라는 총 이진 관계를 부여함으로써 이루어집니다. 이는 매우 간단한 구조입니다: $X$ 의 모든 x 와 y 에 대해 $x ≤ y$ (그리고 따라서 $y ≤ x$) 가 성립한다는 것을 의미합니다.
\end{examplebox}


\begin{examplebox}[Example  1.34]
불리언 집합 {false, true}은 전순서(preorder)를 이룬다.  false ≤ true.
\end{examplebox}


1.35 (부분순서는 골격성 전순서이다)

전순서는 부분순서가 되기 위해 추가적으로 x  y 라면 x  y 를 만족해야 한다.  범주 이론 용어로, x  y 라면 x  y 를 요구하는 것은 골격성이라고 알려져 있으므로, 부분 순서는 골격성 전순서이다. 간단히 말해서, 포셋(partially ordered set)이라는 단어도 사용한다.  전순서와 부분 순서 사이의 차이는 상당히 작다. 부분 순서는 이미 전순서이며, 모든 전순서는 x  y 라는 조건을 만족하는 모든 x, y에 대해 x = y로 같게 만들어 부분 순서로 만들 수 있다. 예를 들어, 어떤 이산 전순서는 이미 부분 순서이고, 어떤 여이산 전순서는 단 하나의 원소 집합에서 유일한 부분 순서가 된다.
